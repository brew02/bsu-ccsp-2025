Obfuscation is the process of making small changes in code in order to make its purpose unclear or hard to understand, while maintaining the original functionality. This is a common technique used with malicious code in order to evade detection. One common technique is inserting Dead code, or a section of assembly code, that is functionally irrelevant and does not contribute to the functionality of the program. These instructions are "dead" because they have no impact on the program's behavior. Examples include: "nop", "mov eax, eax", and "add eax, 0". An active example is the following:
