# Obfuscate and Validate

## Setup

Run the following command to create a virtual environment:

```
python -m venv [env_name]
```

Where `env_name` is the name of the virtual Python environment.

Run this command on Windows to load the environment:

```
.\[env_name]\Scripts\activate
```

Run this command to install angr:

```
python -m pip install angr
```
