Malware is any software designed to intentionally harm, exploit, or take unauthorized control of a computer system, network, or data. Malware authors use tactics such as obfuscation to hide the purpose of their programs. Modern malware detectors look for certain behaviors in code in order to determine if it could be malicious or not. Common behaviors to look for include:
1. Exploiting vulnerabilites: Programming beyond boundaries of the buffer, injecting malicious code into memory, or using format string functions to read or write into memory. 
2. Controlling the program flow: Using jmp instructions to alter the normal execution of the program which can possibly lead to skipping security checks, or using function calls to alter the flow of program execution. 
3. Manipulating data: Moving or modifying data in an unclear way. 

Some important characteristics of important functions that need to be looked at in order to tag it as malicious includes:
1. Signs of obfuscation: This could be having an excess of "nop" instruction, having a lot of "dead" instructions where they add no functionality to the program, or having unclear function and variable names. 
2. Proximity to APIs: Functions that call or wrap APIs such as WinExec, CreateProcess, ReadFile, VirtualAlloc, Send, etc., are often key. 
3. Function calls: Functions that call many other functions, or rather are called by a lot of other functions, usualy hold a lot of importance. 
4. Fucntion size: Functions with larger sizes usually hold more important content.
